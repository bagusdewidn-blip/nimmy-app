## 📥 Cara Mengunduh & Memasang (Installation Guide)

1. Buka tab **[Releases](https://github.com/bagusdewidn-blip/nimmy-app/releases/latest)**.
2. Unduh file `nimmy-stream-vX.X.X.apk` di bagian **Assets**.
3. Buka file APK yang sudah diunduh di perangkat Android Anda.
4. Jika muncul peringatan keamanan *"Sumber tidak dikenal"* (*Install unknown apps*):
   - Masuk ke **Pengaturan (Settings) > Keamanan (Security)** atau klik **Izinkan (Allow)** pada peramban/file manager Anda.
5. Selesaikan proses instalasi dan nikmati tayangan anime favorit Anda!

## ✨ Fitur Unggulan

- 📺 **Streaming Multi-Resolusi**: Dukungan HLS (HTTP Live Streaming) dengan pemutar ExoPlayer modern.
- 💬 **Danmaku Floating Comments**: Komentar melayang real-time selama video diputar.
- 🎨 **Liquid Glass iOS Design**: Desain antarmuka modern dengan efek kaca (glassmorphism), blur dinamis, dan animasi halus.
- ⭐ **Bookmarks & History**: Pantau riwayat tontonan dan simpan anime favorit Anda secara offline di perangkat.
- ⚡ **Ringan & Hemat Kuota**: Dioptimalkan untuk performa tinggi di berbagai versi Android (Android 7.0+ / SDK 24+).
